# CourseWork Variant 2

Курсова робота з дисципліни «Об’єктно-орієнтоване програмування».

Предметна область: інтернет-магазин електроніки.

## Проєкти

 `Domain.Core` - моделі предметної області, бізнес-логіка, репозиторій, JSON-сервіс і власні винятки.
 
 `ConsoleApp` - консольне меню та взаємодія з користувачем.

## Запуск

Відкрити `CourseWork_Variant2.slnx` у Visual Studio і запустити проєкт `ConsoleApp`.

Дані автоматично завантажуються з JSON-файлів у папці `data`. Якщо файлів ще немає, програма створює початковий набір товарів і клієнтів. Перед виходом дані зберігаються.

Тестові купони: `WELCOME10` і `TECH15`.
