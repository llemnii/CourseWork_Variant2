# Орієнтовний план пояснювальної записки

1. Титульний лист.
2. Зміст.
3. Опис завдання та варіанта 2.
4. Опис бізнес-частини проєкту:
   - `Product`, `Category`, `Customer`, `Order`, `OrderItem`;
   - `IRepository<T>` та `InMemoryRepository<T>`;
   - `EntityBase`;
   - `StoreService`;
   - `OutOfStockException` та `InvalidDiscountException`.
5. Опис інтерфейсної частини:
   - головне меню;
   - пошук товарів за брендом;
   - створення замовлення;
   - використання купона;
   - збереження і вихід.
6. Опис роботи з файлами через `JsonFileService<T>`.
7. Лістинги важливих фрагментів коду.
8. Скріншоти:
   - структура Solution у Visual Studio;
   - список товарів;
   - пошук за брендом;
   - створення замовлення зі знижкою;
   - повідомлення про відсутність товару або неправильний купон;
   - JSON-файли збережених даних.
9. Висновки.
